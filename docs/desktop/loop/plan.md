每轮的目标、交付与验收条件。状态：计划中、进行中、完成。

## L0 骨架

- **状态：**完成（2026-10-27）。打包的应用目录带 AOT 缓存时首帧约 1.1–1.3 s；`java -jar` 约 1.7 s，
  `javafx:run` 约 2.2 s（从类目录运行，不能使用 AOT 缓存），见[流畅度](../performance.md)
- **交付：**`desktop/pom.xml`（JavaFX 25.0.5、sqlite-jdbc、Jackson、JUnit 6，Spotless 与零警告）；
  `Launcher` 与 `DesktopApp`；`~/.datacraft` 的初始化与 SQLite 迁移；外壳（侧栏、顶栏、视图切换与懒加载）；
  浅色与深色主题样式表、内置 Barlow 字体、图标；窗口位置与上次视图的保存。
- **验收：**
  - `verify` 通过，0 条警告；
  - 应用启动，控制台 0 条警告，冷启动 ≤ 1.5 s；
  - 关闭后再打开，窗口位置、大小、主题与上次的视图都恢复；
  - `~/.datacraft/datacraft.db` 的 `user_version` 为当前版本。

## L1 连接

- **状态：**完成（2026-10-27）
- **交付：**`HttpTransport`、`EngineClient`（健康、作业目录）、`AirflowClient`（登录与续期、健康、版本）；
  `SecretVault`（Windows DPAPI，其他系统密钥文件）；连接配置的增删改与“测试连接”；`ConnectionMonitor`
  与退避；顶栏的状态点与延迟。
- **验收：**
  - 接口测试覆盖成功、401 与重新登录、403、404、超时、连接被拒、畸形 JSON；
  - 秘密在数据库里只以密文存在，删除配置即删除密文；
  - 对本机 `serve-api` 与 Compose 部署的 Airflow，“测试连接”分别显示正常与延迟；停止服务后 5 s 内显示
    不可达并开始退避，恢复后自动恢复。
