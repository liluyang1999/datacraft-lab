## 修复与取舍

| 范围 | 原有问题 | 本轮处理 |
| --- | --- | --- |
| 本机测试可运行性 | Windows 上 HTTP/Spark 测试因 Selector 失败；符号链接测试报错；stdout 与结果文件换行不同 | 测试 JVM 使用 `-Djdk.net.unixdomain.tmpdir`；缺少前置条件时仅在 Windows 上 abort/cancel；输出统一为 UTF-8 + LF 字节 |
| 执行引擎 | `Error` 逃出引擎，CLI 无结构化结果、HTTP 挂起；异常信息丢失 | 除 `VirtualMachineError` 外全部转为 FAILED 并记录堆栈；作业名禁止 `/` |
| HTTP API | HTML 404、HEAD 不可用、原始非 ASCII 乱码、浏览器跨源可触发作业、停机强制中断 | 兜底 500、JSON 404、HEAD、400、Origin 403、8 秒排空；URI 无法解析的请求仍由 JDK 返回 HTML 400 |
| CLI 与配置 | `--config` 错误退出码 1；BOM 吞首键；值被 trim；默认 master 覆盖 spark-submit | 退出码 0/1/2 可测试；去 BOM；值原样；主节点优先级为参数 > `--master` > 配置 > 启动器 > `local[*]` |
| IO 与 SFTP | junction 越界、递归删除越界；SFTP 通配符误删/误覆盖；下载失败截断旧文件；CSV 写入有损 | 真实路径根校验；字面路径；临时文件原子替换；写入保真；嵌入式 SSHD 集成测试 |
| Spark | 参数错误晚于会话启动；HDFS 别名与 glob 绕过重叠检查；JSON 计数宽松 | 先校验后启动；PathGuards；`DATACRAFT_DATA_ROOT`；FAILFAST 计数；启动器 master/分区继承 |
| 纯 JVM 作业 | README 承诺“纯 JVM 覆盖小场景”，但只有库 | 新模块 `datacraft-jobs`：`csv-profile`、`file-checksum`，数据根约束，读取前与解析前的堆预算 |
| Airflow | 触发参数路径不受限；SFTP 默认不校验主机密钥；`.sh` 参数被当模板 | 数据根参数模式（拒绝 `.`/`..`、glob、控制字符与尾部空白）；主机密钥守卫；字面参数；3.3.2 |
| 镜像与部署 | FAB 认证类 CVE；API 以 root 运行；缺失机密回退弱默认；Swarm 初始化依赖运行中 scheduler | 3.3.2/FAB 3.9.0；UID 10001；`${VAR:?}`；init 服务、日志与健康检查；stdin 传管理员密码；API 只读挂载数据根 |
| 构建与供应链 | 瘦 jar 缺 Multi-Release；Checkstyle 9.3 不认 Java 21+ 语法；Jackson 公告；Wrapper 无校验 | MR 清单；Checkstyle 14.1.0；Jackson 2.22.3 并禁用旧版；Apache 脚本式 Wrapper + SHA-256；引擎边界规则 |
| CI | Node 20 旧动作、仅标签固定；未断言测试真实执行 | 最新主版本固定 SHA、ubuntu-24.04；模块执行数下限；jar 清单/算法探针/退出码冒烟；缺失机密拒绝检查 |
| 文档 | 历史快照被当作当前报告；孤立页面、机器相关路径、错误归因 | 统一评估报告 v2.0、勘误、文档一致性测试 |

取舍：API 仍无认证，依靠回环绑定、Origin 检查和数据根约束，远程访问必须经认证网关；
`row-count` 为只读计数，不受数据根约束；Swarm 仍固定单数据节点，未做真实多节点演练；
Maven Wrapper 在 Linux/macOS 上需要 `unzip`（否则下载 `.tar.gz` 并以校验失败退出）。

## 可重复验证

```bash
./mvnw -B -ntp verify
python3 -B -m unittest discover -s deploy/tests -v
python3 -B .github/scripts/check_test_counts.py .
python3 -B -m unittest discover -s orchestration/airflow/tests -v
python3 -B orchestration/airflow/tests/runtime_smoke.py --jar datacraft-cli/target/datacraft-cli.jar
node --test deploy/tests/cloud-costs.test.cjs
bash deploy/tests/container_smoke.sh && bash deploy/tests/compose_smoke.sh
```

Airflow 相关命令需要按 [Airflow 指南](../../orchestration/airflow/README.md) 安装 3.3.2 与官方 constraints；
最后一行需要 Docker。Windows 上执行 Maven 时，符号链接测试需要开发者模式，写 Parquet 的 Spark 测试需要 winutils，
缺少时这些测试被标记为跳过或取消；`check_test_counts.py` 的下限按 Linux 计数，因此只在 Linux 上作为门禁。

## 清理与适用边界

审查与实施使用的隔离工作区、临时虚拟环境、下载的探针与测试日志都不纳入版本库，并在结束时删除；
提交只包含代码、测试与文档。没有购买或部署云资源，没有连接生产数据库、真实 SFTP 账号或集群。
升级既有部署前请阅读部署指南中的升级步骤：机密缺失将直接失败、DAG 改为打入镜像、Swarm 需要具体镜像标签、
SFTP 连接需要 `host_key`。
