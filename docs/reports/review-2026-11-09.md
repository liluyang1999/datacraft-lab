从干净的 `cb600c764eb41d32f94dab0dff3067938eff02d4` 开始。沿用已有模块边界、
公开作业名称、数据库结构及各语言命名惯例；本轮以可复现的行为缺口为依据，

## 修复与回归

- 非法 UTF-8 作业路径原先被替换为 U+FFFD，可能执行另一个已注册作业。
  新回归真实得到 HTTP 200 后，改为从原始路径严格解码一次，非法序列返回 400 且不执行。
  合法中文、U+FFFD、字面加号、编码加号和双重编码均保留原语义；查询参数的加号仍表示空格。
- 切换作业立即移除上一作业的运行记录，加载、失败与空态分别呈现；代次校验拒绝迟到结果。
  总览读取本机历史失败时保留上次成功快照并提供重试说明；清空缓存或切换连接时同步清除快照。
  原回归分别复现旧记录残留、成功统计被误减，修复后针对性验证通过。
- 共享详情入口支持键盘打开、滚动阅读、选择及复制完整原文。五个页面的长诊断使用短入口；
  结果指标只缩略已知计数，详情与复制保留原始值。长名称和图节点约束显示宽度，
  流水线、作业、活动和设置保留完整信息的查看方式。
  150 行通知原先会遮挡页面，新增高度回归失败后改为 80 码点摘要和全文详情；
  短通知、最多三条、手动关闭和既有生命周期保持不变。
- 负耗时原先产生 NaN，超大耗时原先在毫秒转换时溢出；柱高改为有限非负计算，
  时长显示避免溢出并使用有界单位。新增回归先失败后通过。
- Windows 步骤包装器原先被后台子进程继承的输出管道拖住，绕过两秒收尾上限。
  跨平台握手回归先在十秒内无法返回，修复使用 Python 支持的非阻塞管道读取，
  保留命令退出码、输出和失败注解；测试自行正常结束子进程，不杀死不归属的进程。
- 桌面 CI 在第一个包装步骤前显式选择 Python 3.13，不依赖 Windows 运行机的默认版本。
  复用现有固定 Action SHA；新增契约在旧配置上失败，修复后两平台通过。
